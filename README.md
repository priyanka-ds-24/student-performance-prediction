# Student Performance Prediction System (Intermediate AI/ML)

## Overview
This project predicts the final grade (`G3`, on a 0–20 scale) using the UCI Student Performance dataset. It includes data quality checks, EDA, preprocessing pipelines, model comparison, cross-validation, error analysis, a saved model, and an interactive Streamlit application.

## Dataset
Download the official UCI Student Performance dataset:
https://archive.ics.uci.edu/dataset/320/student+performance

Place `student-mat.csv` in this project root. The CSV is semicolon-separated. The source dataset concerns secondary-school students in two Portuguese schools; do not describe it as a representative sample of all students.

## Setup (Windows / VS Code)
```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```


## Project design
Two prediction scenarios are compared:
1. `early_warning`: excludes `G1` and `G2` to simulate prediction before period grades are available.
2. `with_period_grades`: includes `G1` and `G2`, which can improve prediction because they are prior grades.

Do not select a scenario only because it has a better score. Explain when its inputs would be available in real use. Preprocessing is fitted inside each training pipeline to reduce leakage. The holdout set is used for evaluation; cross-validation is performed on training data.

## Metrics
- MAE: average absolute error in grade points; lower is better.
- RMSE: penalizes larger errors more strongly; lower is better.
- R²: proportion of target variance explained relative to a mean baseline; closer to 1 is generally better, but it can be negative.

## Important limitations
- This is an educational project, not a validated tool for real student placement, grading, discipline, or high-stakes decisions.
- Predictions may be inaccurate and should not be used to label or limit students.
- The dataset is small and specific to two schools; results may not generalize.
- Relationships are not proof of causation.
- Features such as family circumstances and demographic attributes raise fairness and privacy concerns. Use the project for learning and discuss these limitations.
- Model metrics are generated when you run the code. No performance score is promised in advance.
